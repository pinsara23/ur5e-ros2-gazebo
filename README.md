# UR5e ROS 2 Gazebo Simulation & Python Control

A ROS 2 robotics project for learning and developing robotic-arm control using a simulated **Universal Robots UR5e**.

The project uses an existing UR5e simulation rather than building the robot model from scratch. The main goal is to understand how ROS 2, Gazebo, `ros2_control`, actions, Python, and eventually MoveIt 2 work together to control a robotic arm.

---

## 🎯 Project Goals

The long-term goal of this project is to develop a complete ROS 2 robotic-arm system that can:

* Control a simulated UR5e using custom Python programs
* Understand ROS 2 communication and robot control
* Generate and execute joint trajectories
* Control the robot through multiple waypoints
* Use MoveIt 2 for motion planning
* Control the robot using end-effector positions
* Perform pick-and-place tasks
* Integrate cameras and computer vision
* Eventually experiment with AI-based robotic control

This repository is also being used as a learning project to understand robotics concepts by implementing them step by step.

## 🏗️ System Architecture

The current system follows this control pipeline:

```text
┌───────────────────────┐
│   Custom Python Node  │
│        rclpy          │
└───────────┬───────────┘
            │
            │ FollowJointTrajectory Action
            ▼
┌──────────────────────────────┐
│ scaled_joint_trajectory_     │
│ controller                   │
└──────────────┬───────────────┘
               │
               │ ros2_control
               ▼
┌──────────────────────────────┐
│       UR5e Robot             │
│        Simulation            │
└──────────────┬───────────────┘
               │
               ▼
┌──────────────────────────────┐
│     Gazebo Harmonic          │
└──────────────────────────────┘
```

The Python program does not directly control Gazebo.

Instead, it sends a trajectory goal through a ROS 2 action to the active `scaled_joint_trajectory_controller`, which is responsible for controlling the simulated robot joints.

## 🚀 Running the Project

### 1. Source ROS 2

```bash
source /opt/ros/jazzy/setup.bash
```

### 2. Source the workspace

```bash
source ~/robot_ws/install/setup.bash
```

### 3. Start the UR5e simulation

```bash
ros2 launch ur_simulation_gz ur_sim_control.launch.py ur_type:=ur5e
```

This starts the UR5e simulation in Gazebo and launches the required ROS 2 control components.

### 4. Run the Python controller

In another terminal:

```bash
source /opt/ros/jazzy/setup.bash
source ~/robot_ws/install/setup.bash
```

Then:

```bash
ros2 run ur5e_python_control move_ur5e
```

The Python node connects to the trajectory controller and sends the configured joint trajectory.

## 🔍 Useful ROS 2 Commands

Check the active controllers:

```bash
ros2 control list_controllers
```

Check the robot joint states:

```bash
ros2 topic echo /joint_states --once
```

List available actions:

```bash
ros2 action list
```

Inspect the UR5e trajectory action:

```bash
ros2 action info /scaled_joint_trajectory_controller/follow_joint_trajectory
```

# 📖 Project Philosophy

This project is not intended simply to demonstrate a working robot simulation.

The main objective is to **understand how robotic systems work internally** and progressively build more capable control programs.

The development process is:

```text
Understand
    ↓
Implement
    ↓
Test
    ↓
Debug
    ↓
Improve
    ↓
Build the next layer
```

Each stage builds on the previous one.
