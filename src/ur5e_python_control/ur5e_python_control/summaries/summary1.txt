31. PYTHON CODE WE USED
=======================

The program conceptually used the following code:

import rclpy
from rclpy.node import Node
from rclpy.action import ActionClient

from control_msgs.action import FollowJointTrajectory
from trajectory_msgs.msg import JointTrajectoryPoint

class UR5eController(Node):

```
def __init__(self):
    super().__init__('ur5e_controller')

    self._action_client = ActionClient(
        self,
        FollowJointTrajectory,
        '/scaled_joint_trajectory_controller/follow_joint_trajectory'
    )

    self.get_logger().info('UR5e controller started')


def move_robot(self):

    self.get_logger().info(
        'Waiting for UR5e controller...'
    )

    self._action_client.wait_for_server()

    self.get_logger().info(
        'Controller connected!'
    )


    goal = FollowJointTrajectory.Goal()


    goal.trajectory.joint_names = [
        'shoulder_pan_joint',
        'shoulder_lift_joint',
        'elbow_joint',
        'wrist_1_joint',
        'wrist_2_joint',
        'wrist_3_joint'
    ]


    point = JointTrajectoryPoint()

    point.positions = [
        0.3,
        -1.57,
        0.0,
        -1.57,
        0.0,
        0.0
    ]

    point.time_from_start.sec = 3


    goal.trajectory.points.append(point)


    self.get_logger().info(
        'Sending trajectory to UR5e...'
    )


    future = self._action_client.send_goal_async(goal)

    rclpy.spin_until_future_complete(
        self,
        future
    )


    goal_handle = future.result()


    if not goal_handle.accepted:

        self.get_logger().error(
            'Goal was rejected!'
        )

        return


    self.get_logger().info(
        'Goal accepted!'
    )


    result_future = goal_handle.get_result_async()

    rclpy.spin_until_future_complete(
        self,
        result_future
    )


    result = result_future.result().result


    if result.error_code == 0:

        self.get_logger().info(
            'UR5e reached the target position!'
        )

    else:

        self.get_logger().error(
            f'Movement failed: {result.error_string}'
        )
```

def main(args=None):

```
rclpy.init(args=args)

robot = UR5eController()

robot.move_robot()

robot.destroy_node()

rclpy.shutdown()
```

if **name** == '**main**':
main()

32. WHAT EACH IMPORTANT PYTHON PART DOES
========================================

import rclpy

PURPOSE:
Python interface for ROS 2.

from rclpy.node import Node

PURPOSE:
Allows our Python class to become a ROS 2 node.

from rclpy.action import ActionClient

PURPOSE:
Allows our program to communicate with a ROS 2 action server.

from control_msgs.action import FollowJointTrajectory

PURPOSE:
Defines the action used to send joint trajectories to the robot controller.

from trajectory_msgs.msg import JointTrajectoryPoint

PURPOSE:
Represents one point in a robot joint trajectory.

class UR5eController(Node):

PURPOSE:
Creates our own ROS 2 node.

super().**init**('ur5e_controller')

PURPOSE:
Gives the ROS 2 node the name:

ur5e_controller

ActionClient(...)

PURPOSE:
Creates a client that can communicate with:

/scaled_joint_trajectory_controller/follow_joint_trajectory

wait_for_server()

PURPOSE:
Waits until the robot's action server is available.

FollowJointTrajectory.Goal()

PURPOSE:
Creates the goal that will be sent to the robot controller.

goal.trajectory.joint_names

PURPOSE:
Defines which robot joints the trajectory controls.

The order is extremely important:

1. shoulder_pan_joint
2. shoulder_lift_joint
3. elbow_joint
4. wrist_1_joint
5. wrist_2_joint
6. wrist_3_joint

point.positions

PURPOSE:
Defines the desired angle of every joint.

Example:

[
0.3,
-1.57,
0.0,
-1.57,
0.0,
0.0
]

Each value corresponds to the joint in the same position in
joint_names.

point.time_from_start.sec = 3

PURPOSE:
Says that the robot should reach this trajectory point at 3 seconds.

goal.trajectory.points.append(point)

PURPOSE:
Adds the trajectory point to the trajectory.

send_goal_async()

PURPOSE:
Sends the trajectory goal to the controller.

rclpy.spin_until_future_complete()

PURPOSE:
Waits for the asynchronous ROS 2 operation to finish.

goal_handle.accepted

PURPOSE:
Checks whether the controller accepted the goal.

get_result_async()

PURPOSE:
Requests the final result from the action server.

result.error_code

PURPOSE:
Tells us whether the trajectory succeeded or failed.

0 means success.

rclpy.init()

PURPOSE:
Starts the ROS 2 Python system.

robot.destroy_node()

PURPOSE:
Cleans up our ROS 2 node.

rclpy.shutdown()

PURPOSE:
Shuts down the ROS 2 Python system.
