# 3. What MoveIt 2 Is

MoveIt 2 is a ROS 2 framework for robot motion planning.

Without MoveIt:

```text
Our program decides the exact joint trajectory.
```

With MoveIt:

```text
Our program specifies a goal.

MoveIt decides how to reach it.
```

For example, without MoveIt we previously created:

```python
point.positions = [
    0.5,
    -1.2,
    -0.5,
    -1.3,
    0.2,
    0.0
]

point.time_from_start.sec = 4
```

We explicitly told the robot which joint positions it should reach.

MoveIt allows us to provide:

```text
START
+
GOAL
```

and calculate the intermediate motion automatically.

---

# 4. Planning vs Execution

One of the most important Stage 4 concepts was the difference between planning and execution.

Planning:

```text
Current RobotState
        ↓
Goal RobotState
        ↓
Motion planner
        ↓
Collision checking
        ↓
Path
        ↓
Time parameterization
        ↓
RobotTrajectory
```

No physical/simulated movement is required during this process.

Execution happens afterward:

```text
RobotTrajectory
        ↓
Trajectory Execution Manager
        ↓
ros2_control controller
        ↓
Gazebo
        ↓
UR5e moves
```

Therefore:

```text
Planning = calculate the motion

Execution = perform the motion
```

# 54. Meaning of `base_link`

This line:

```python
collision_object.header.frame_id = "base_link"
```

means that the box's coordinates are measured relative to the UR5e base frame.

For example:

```python
x = 0.50
y = 0.50
z = 0.50
```

means approximately:

```text
0.50 m along X
0.50 m along Y
0.50 m along Z
```

from the robot's `base_link` coordinate frame.

# 68. Final Stage 4 Python Building Blocks

The main imports:

```python
import time
import copy

from moveit_configs_utils import MoveItConfigsBuilder

    MoveItPy,
    PlanRequestParameters
```

MoveIt configuration:

```python
moveit_config = (
    MoveItConfigsBuilder(
        robot_name="ur",
        package_name="ur_moveit_config"
    )
    .robot_description_semantic(
        Path("srdf") / "ur.srdf.xacro",
        {"name": "ur5e"}
    )
    .planning_pipelines(
        pipelines=["ompl"],
        default_planning_pipeline="ompl"
    )
    .to_moveit_configs()
)

config_dict = moveit_config.to_dict()

    "pipeline_names": ["ompl"]
}

config_dict["use_sim_time"] = True
```
